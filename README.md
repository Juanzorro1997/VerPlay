# VerPlay

VerPlay es una plataforma web experimental para visualizar y descubrir vídeos.

El proyecto está diseñado para funcionar como una página estática mediante GitHub Pages.

## Características

- 🎬 Reproductor de vídeos
- 🔎 Búsqueda de vídeos
- 🎮 Categorías
- 📱 Diseño responsive
- ⬆️ Selección de vídeos locales
- 🌙 Interfaz oscura
- ⚡ Sin backend para la versión inicial
